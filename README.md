# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.


Задания №1
Сделан сервер. Стоковый адресс береться из переменной DefaultPort. Сделанна отдельная функция по созданию адресса в которой 
проверяеться существования переменной окружения "TODO_PORT". Если переменная окружения существует и входит в пул разрешенных
адрессов сервер начинать работать на порту переменной окружения. Если порт переменной окружения все таки не подходит, то сервер
запускаеться на порту DefaultPort (7540 в данной версии). Также сделан хэндлер, который подвязывает статические файлы к серверу.

## 📋 О проекте
**Todo-list** — это полнофункциональное приложение для управления персональными 
и рабочими задачами. Проект сочетает в себе:

### 🎯 Основные возможности:
- ✅ **REST API** — полный CRUD для работы с задачами
- 🌐 **Веб-интерфейс** — интуитивно понятный UI для ежедневного использования  
- 🔐 **Безопасность** — HTTP Basic Auth для защиты доступа
- 🐳 **Docker-поддержка** — запуск в один клик в изолированном окружении
- ⚙️ **Гибкая настройка** — конфигурация через переменные окружения

### 🛠 Технологический стек:
- **Backend**: Go (чистая архитектура, net/http)
- **База данных**: SQLite (легковесная, файловая)
- **Фронтенд**: Статический HTML/CSS/JS
- **Инфраструктура**: Docker, многоступенчатая сборка

## ⚙️ Конфигурация (Environment Variables)

Приложение настраивается с помощью переменных окружения. Вы можете задать их в системе, через `.env` файл или при запуске Docker.

| Переменная | Описание | Значение по умолчанию | Обязательная |
|------------|----------|-----------------------|--------------|
| `TODO_PORT` | Порт, на котором запускается HTTP-сервер. **Если переменная не задана**, используется порт `7540` | `7540` | Нет |
| `TODO_DBFILE` | Путь к файлу базы данных SQLite. Может быть абсолютным или относительным. Папка будет создана автоматически | `./data/` | Нет |
| `TODO_DBTESTDATA` | При значении `"true"` (строка) база будет заполнена тестовыми данными | - (без тестовых данных) | Нет |
| `TODO_PASSWORD` | Пароль для HTTP-базовой авторизации. **Если переменная не задана или пустая**, авторизация полностью отключена | - (авторизация отключена) | Нет |

## 🐳 Docker

Проект может быть запущен в изолированном Docker-контейнере. Готовый `Dockerfile` использует многоступенчатую сборку для создания минимального образа.

### Особенности образа
- **Многоступенчатая сборка**: Сначала компилируется Go-приложение, затем копируется в минимальный образ Ubuntu
- **Минимальный размер**: Итоговый образ содержит только приложение, папку `web` и папку `migrations`
- **Порт по умолчанию**: Контейнер слушает на порту `7000`
- **Предустановленные переменные**: В образ встроены значения по умолчанию для быстрого старта

### Предварительные требования
- [Docker](https://docs.docker.com/get-docker/) установленный на вашей машине
- Минимум 512 MB свободной памяти

### Сборка Docker-образа
> [!IMPORTANT]
> Перед тем как собирать и запускать Docker-образ убедитесь в том, что делаете это в корне проекта.

1. **Сборка Docker-образа**:
```bash
docker build -t todo-list .
```
2. **Запуск Docker-образа**:
```bash
docker run -d -p 8080:7000 todo-list
```
3. **Запуск Docker-образа c полной конфигурацией**: 
```bash
docker run -d --name todo-list -p 8080:7000 -e TODO_PASSWORD="12345" -e TODO_PORT=7000 -e TODO_DBFILE="./data/" -e TODO_DBTESTDATA="true" todo-list
```
> [!TIP]
> Готово! Сервер запущен и доступен по адресу:
> 🔗 http://localhost:8080/
